Privacy Policy - ui-preset-reader

Made by hplgala. Last updated: November 17, 2026.

ui-preset-reader is a personal, single-user tool. It is used only by its owner to read the owner's own Pinterest boards and pins and to organize them as private design references.

What data it accesses

Only the owner's own boards and pins (titles, descriptions, links and images), read through the Pinterest API with the owner's permission. It does not access any other Pinterest user's data.

How the data is used and stored

Only to build the owner's private reference collection. Stored only on the owner's own computer and private workspace. Never sold, shared with third parties, or used for advertising. The tool does not create, edit or delete pins or boards.

Deleting data and revoking access

The owner can revoke access at any time in Pinterest settings and delete all local copies.
